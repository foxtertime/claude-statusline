# claude-statusline

Статуслайн для [Claude Code](https://claude.com/claude-code): директория, git-ветка со статусом, модель с размером контекста и уровнем effort, шкала заполнения контекста и лимиты использования с временем сброса на русском.

```
~/projects/app │ main +2 ~1 ?3 ↑1
Opus 5 (1M) (high) │ Ctx ━━────────────────── 12% (125K / 1000K)
Current ━━━━━─────────────── 23%  02:40
Weekly  ━━━━━━━━──────────── 41%  4 сен, 12:00
Sonnet  ━━────────────────── 8%   4 сен, 12:00
```

Что показывается:

- **Строка 1** — текущая директория; git-ветка с индикаторами: staged (`+`), modified (`~`), untracked (`?`), конфликты (`!`), ahead/behind (`↑`/`↓`), stash, последний коммит. Без git-репозитория — `[no git]`.
- **Строка 2** — модель, размер контекстного окна, уровень effort; шкала заполнения контекста с процентом и токенами.
- **Строки 3+** — лимиты использования: 5-часовое окно, недельное, отдельно Sonnet; время сброса в 24-часовом формате («19:30» если сегодня, иначе «10 мар, 19:30»).

## Установка

```bash
git clone https://github.com/<ваш-логин>/claude-statusline.git
cd claude-statusline && ./install.sh
```

Затем перезапустите Claude Code.

Установщик кладёт скрипт в `~/.claude/statusline.sh` и добавляет в `~/.claude/settings.json`:

```json
"statusLine": { "type": "command", "command": "~/.claude/statusline.sh" }
```

Существующий `settings.json` не перезаписывается — только добавляется ключ `statusLine` (с бэкапом в `settings.json.bak`).

## Обновление

```bash
cd claude-statusline && git pull && ./install.sh
```

## Зависимости

- Обязательно: `bash`, `jq`, `bc`
- Опционально: `git` (без него не отображается git-блок), GNU `date` (на macOS флаг `date -d` не работает — не будет времени сброса лимитов, остальное работает)
